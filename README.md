# OpenSearch for Drupal

This project provides an MCP (Model Context Protocol) server that integrates OpenSearch with Drupal, enabling advanced search capabilities for Drupal-based websites.

## Overview

The OpenSearch for Drupal MCP server acts as a bridge between Drupal content and OpenSearch, allowing AI agents and other MCP clients to perform powerful search operations against Drupal content indexed in OpenSearch.

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- An OpenSearch instance
- A Drupal site with content indexed in OpenSearch

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Deployment

```bash
npm run deploy
```

## Usage

Connect to the MCP server from any MCP-compatible client using the server's SSE endpoint.
